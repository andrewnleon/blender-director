# Practical UI — checklist

## Before shipping UI

- [ ] Contrast passes AA for text and controls
- [ ] Primary action obvious; destructive actions distinct
- [ ] Form labels visible; errors specific and actionable
- [ ] Loading states for async regions (skeleton or spinner)
- [ ] Keyboard focus visible
- [ ] Works in light and dark mode

## Forms

- Single column on mobile
- Mark required fields
- Submit button disabled + loading state during async submit

## Copy

- Sentence case headings
- Front-load error messages: what failed + how to fix
