# Practical UI

Logic-driven UX (Adham Dannaway, *Practical UI*). Load before **app-ui**.

## Non-negotiables

- WCAG 2.1 AA: 4.5:1 body text; 3:1 large text and controls
- Logical reason for each design choice
- Minimize interaction cost and cognitive load
- Don't rely on color alone
- Forms: single column, visible labels
- Buttons: clear verb+noun labels, adequate touch targets
- Copy: sentence case, concise errors

## Hierarchy

1. **practical-ui** — UX logic wins on conflicts
2. **app-ui** — shadcn tokens and spacing

Full checklist: `guidelines.md` in this folder.
