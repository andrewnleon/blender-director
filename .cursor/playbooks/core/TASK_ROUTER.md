# Task Router

Consult before routing. Caveman always on.

## Priority

1. Security → `security` (+ `api-engineer` if routes)
2. Data → `data-engineer` (when DB wired)
3. Stability / architecture → `lead-engineer` + specialist
4. Performance → `ui-engineer` or `api-engineer`
5. UX polish → `ui-engineer`

## No-Drift

Redesign / rebrand / layout refactor without explicit OK → STOP and ask.

## Escalation to lead-engineer

New dependencies, major API/routes, cross-cutting refactors.

## Lean default

Single-file fixes: short plan → one specialist → verify.
